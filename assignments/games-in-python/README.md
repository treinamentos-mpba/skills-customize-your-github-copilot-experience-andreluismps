
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras em Python. A atividade pratica manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Escolher a palavra e processar palpites

#### Descrição

Implemente a seleção aleatória de uma palavra e permita que o jogador adivinhe uma letra por vez. Mostre as letras corretas nas posições correspondentes e o progresso da palavra.

#### Requisitos

O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso da palavra no formato `_ _ _`.

### 🛠️ Controlar tentativas e encerrar a partida

#### Descrição

Controle as tentativas incorretas e encerre a partida quando o jogador adivinhar a palavra ou não tiver mais tentativas disponíveis.

#### Requisitos

O programa concluído deve:

- Rastrear e exibir as tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir uma mensagem de vitória ou derrota ao final do jogo.
